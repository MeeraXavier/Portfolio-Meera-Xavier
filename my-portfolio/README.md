# 🌐 Personal Portfolio – Next.js & Tailwind CSS

A modern, responsive personal portfolio built using **Next.js**, **TypeScript**, and **Tailwind CSS** to showcase my skills, experience, and projects as a Frontend Developer.

---

## ✨ Features

- ⚡ Built with **Next.js (App Router)**
- 🎨 Styled using **Tailwind CSS**
- 🧠 Written in **TypeScript**
- 📱 Fully responsive design
- ✨ Smooth UI & animations
- 🗂️ Clean, scalable folder structure
- 🚀 Deployed on **Vercel**

---

## 🛠️ Tech Stack

- **Framework:** Next.js 14
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **State Management:** Redux / RTK / Zustand
- **Data Fetching:** React Query
- **Charts:** React ECharts
- **Deployment:** Vercel
