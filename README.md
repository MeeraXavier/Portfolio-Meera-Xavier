# Portfolio – Meera Xavier 🌍

A personal portfolio website built using **React**, **TypeScript**, and **Tailwind CSS** to showcase my work, experience, and skills as a Frontend Developer.

## 🚀 Features
- Responsive and modern UI with Tailwind CSS
- Light/Dark theme switcher 🌙☀️
- Projects section with live links & GitHub repos
- Resume download section 📄
- Contact form (EmailJS integration)
- Deployed on **Vercel**

## 🛠 Tech Stack
- **Framework:** React + TypeScript + Vite
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Form Handling:** EmailJS
- **Deployment:** Vercel

## 📂 Folder Structure

```bash
src/
├── components/   # Reusable UI components
├── pages/        # Main page sections (Home, About, Projects, Contact)
├── assets/       # Images, icons, and other static files
├── hooks/        # Custom React hooks
└── utils/        # Helper functions
